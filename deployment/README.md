# Deployment

Конфигурация деплоя системы.

1. Склонируйте этот репозиторий на сервер. Например в папку `/opt/project`.
2. Зайдите в папку и склонируйте server и web-app.
3. Запустите сборку докер образов `docker compose build`.
4. Запустите систему в фоне `docker compose up -d`

## Почему так?

Этот проект не использует git-submobules. НО предполагается, что внутри папки этого репозитория будут папки других репозиториев. Все добавлено в gitignore, поэтому проблем быть не должно.


### Caddy vs Nginx

Я использую caddy вместо nginx, так как caddy поддерживает автоматическое создание letsencrypt ssl сертификатов для https. Кроме того, я хотел чтобы вся конфигурация была внутри докера. Это упрощает деплой целого сервера. 

Поэтому докер торчит наружу 80 и 443 портами!

Возможно, понадобится nginx перед всем докером, чтобы фильтровать нежелательный трафик.

### Настройка хоста

Базовый шаг: выключить вход по паролю и использовать толлько ssh ключи, добавленные в `~/.ssh/authorized_keys`.

1. Установить `docker`.
2. Установить фаервол `ufw` и закрыть все порты, кроме 22, 80, 443.
3. Установить nginx для проксирования всего трафика в докер с защитой от ддоса.

```shell
sudo apt update
sudo apt upgrade -y

sudo apt install htop mc curl git ufw tmux

# GOTO https://docs.docker.com/engine/install/ubuntu/

# GOTO https://docs.docker.com/engine/install/linux-postinstall/

```
